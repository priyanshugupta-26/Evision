# Model Artifacts Directory

This directory holds serialized model checkpoints, benchmark evaluation logs, and offline forecasts generated by EVision.

## Lightweight Deployment Architecture
In adherence to production deployment guidelines and repository storage constraints:
- Heavy binary model weights and checkpoint files (`*.pkl`, `*.joblib`, `*.ubj`) are excluded from Git commits via `.gitignore`.
- Models are trained deterministically on CPU in sub-second inference passes, using Streamlit memory caching (`@st.cache_data`, `@st.cache_resource`) to provide instant user interactions without persistent disk bloat.
